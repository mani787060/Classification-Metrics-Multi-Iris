# Classification Metrics on Multi-Class Iris Dataset

## 📌 Project Overview

This project demonstrates how to evaluate **multi-class classification models** using the **Iris dataset**. It explains the most commonly used classification metrics and shows how to measure a model's performance across multiple classes.

Using the **Iris_ID.csv** dataset, the notebook trains a classification model and evaluates it using various performance metrics, helping build a strong understanding of model evaluation in multi-class classification problems.

---

## 🎯 Objectives

* Understand multi-class classification evaluation
* Learn the Confusion Matrix
* Calculate Precision, Recall, and F1-Score
* Understand Macro, Micro, and Weighted averages
* Interpret the Classification Report

---

## 📂 Dataset

**Dataset Used:** `Iris_ID.csv`

The Iris dataset contains measurements of iris flowers from three different species and is one of the most popular datasets for classification problems.

## 🔍 Key Observations

* Accuracy alone may not fully describe model performance.
* Precision, Recall, and F1-Score provide deeper insights.
* The Confusion Matrix helps identify class-wise prediction errors.
* Macro, Micro, and Weighted averages are useful for evaluating multi-class problems.
